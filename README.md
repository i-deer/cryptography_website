# Cryptography Website

---------------------------------------------------------------------------------------------------------

Hello, whilst on the Stemettes Mentoring Programme, I wanted to challenge myself to build something to brush up on my HTML and CSS skills from before in secondary school. Creating a website to teach people about cryptography has always been something on my mind. I loved competing in the University of Southampton's National Cipher Challenge and I wanted to share that love forward through the website.

You might have seen this message on some of my other repositories as well. I plan to continue working on the website as part of a wider "project" of mine to go back and revamp previous coding projects I had started and only really reached a MVP for. Just a reminder, exam boards and universities do check for plagarism so I **highly highly** advise against just forking this project and claiming it as your own. Part of the joy of coding is doing the user research, learning about new coding techniques and APIs and being able to watch as your skillset grows.

If anyone did have any feedback or suggestions for the project, I would be more than happy to hear them!
